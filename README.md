# tg-notify

Личный Telegram-бот для уведомлений. Работает на GitHub Actions — свой сервер не нужен.

- **«Отправить сообщение»** — пересылает тебе в Telegram любой текст. Запускается вручную или Claude.
- **«Напоминания по расписанию»** — раз в час проверяет `reminders.yaml` и присылает то, чему пришло время.

Бот только отправляет сообщения и только на твой `chat_id`. Если ему напишет кто-то другой, ничего не произойдёт.

## Настройка

### 1. Бот в Telegram (@BotFather)
1. `/revoke` → выбери бота → получи **новый** токен. Никому его не присылай.
2. `/setjoingroups` → выбери бота → **Disable**, чтобы бота нельзя было добавить в группы.

### 2. Узнай свой chat_id
1. Напиши своему боту `/start`.
2. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив вместо `<ТОКЕН>` свой токен.
3. Найди `"chat":{"id":123456789` — это число и есть chat_id.

Ссылку с токеном никому не показывай.

### 3. Репозиторий — приватный
Settings → General → внизу «Danger Zone» → **Change visibility** → Private.

### 4. Секреты
Settings → Secrets and variables → Actions → **New repository secret**, два раза:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | токен бота |
| `TELEGRAM_CHAT_ID` | твой chat_id |

### 5. Проверка
Actions → **Отправить сообщение** → Run workflow → введи `Тест` → Run. Через ~30 секунд сообщение придёт в Telegram.

Потом Actions → **Напоминания по расписанию** → Run workflow. Первый запуск ничего не присылает, а только создаёт `sent.json`. Дальше всё идёт по расписанию.

## Как добавить напоминание
Открой `reminders.yaml` на GitHub (значок карандаша), скопируй любой блок и поменяй поля. Подсказки по формату — в начале файла. Время всегда пиши в кавычках: `"09:00"`.

## Если что-то не работает
- **Ошибка 401 или «не заданы секреты»** — проверь секреты из шага 4.
- **Ошибка 400 «chat not found»** — неверный chat_id, или ты не написал боту `/start`.
- **Шаг «Сохранить отметки» падает с ошибкой доступа** — Settings → Actions → General → Workflow permissions → **Read and write permissions**.
- **Упавший запуск** GitHub присылает письмом на почту.

## Лимиты
В приватном репозитории GitHub даёт 2000 бесплатных минут Actions в месяц. Ежечасная проверка расходует около 720.
